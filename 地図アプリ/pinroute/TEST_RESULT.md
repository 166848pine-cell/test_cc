## 前回から修正した不具合

正式なテストランナーを通す前に、**実ブラウザで動かして重大な不具合を発見した**。
前回のテストは全ケースPASSしていたが、すべてモックのため見逃されていた。

| # | 不具合 | 影響 |
|---|---|---|
| 1 | 国土地理院APIの結果を並べ替えずに先頭5件を採っていた | 「東京駅」の検索候補が「北海道札幌市東区」等になり、**受け入れ基準1を満たさない**(アプリとして使用不能) |
| 2 | 国土地理院が0件のときしかNominatimへ切り替えない | 「札幌市時計台」→「北海道札幌市」、「六本木ヒルズ」→郵便局 のように、誤った地点で確定してしまう |
| 3 | 同一地点の重複候補をそのまま表示 | 「東京駅」が4件並ぶなど、選べない候補一覧になる |
| 4 | 候補に所在地の表示がない | 「富士山」が5件並んでも区別できない |
| 5 | `#route-bar { display: flex }` が `[hidden]` に勝っていた | ピン0件でも空のルート概要が表示される |
| 6 | パネル内の要素がflexで縮む | 候補が5件あっても2件しか表示されない |
| 7 | Nominatimの `display_name` をそのまま名称に使用 | ピン名が「東京駅, 1, 丸の内一丁目, 千代田区, …」になる |
| 8 | E2Eのモバイル設定がWebKit指定 | テスト計画の「chromium + mobile viewport」と不一致・実行不能 |
| 9 | `crypto.randomUUID` 固定 | セキュアコンテキスト以外(LAN内http配信など)で起動しない |
| 10 | 地図コンテナのリサイズに未追従 | 画面回転・分割比変更で地図が欠ける |
| 11 | 共有URLに再発行されるidを含め、座標も冗長な桁数のまま格納 | 20件のピンで約2,900文字になり、共有URLがほぼ常に「長すぎ」警告になる |
| 12 | ルート計算の完了時にピン一覧全体を再描画 | 遅れて返るルート応答で、ドラッグ中の並び替えが中断され、編集中の入力欄のフォーカスも外れる |
| 13 | `index.html` を直接開くと何も動かない | ブラウザが `file://` のページからスクリプト・CSSを読むのをCORSで禁止しているため。ダブルクリックで開ける1ファイル版 `dist/PinRoute.html` を追加して対処(`PROPOSALS.md` A-6) |
| 14 | 郵便番号付きの住所が0件になる | 「〒160-0023 東京都新宿区西新宿2-8-1」で検索結果0件。見つからないときは郵便番号や建物名を落として調べ直すようにした |
| 15 | 1ファイル版のバンドルが壊れることがある | HTMLへの埋め込みで文字列置換を使っており、JS中の `$&` などが置換パターンとして展開されていた。関数で返すよう修正 |
| 16 | 並び替えのドラッグ中にルート応答が届くと操作が壊れる | 区間行の出し入れで行の位置がずれるため。ドラッグ中は描き換えを保留し、終わってから反映するようにした |
| 17 | 駅の徒歩圏に物件が集まると情報ブロックが重なって読めない | ピンの横に置く固定方式だったため。重なる場合は地図の左右の端に振り分けて縦に並べる自動配置を追加 |
| 18 | ブロックを1つ動かすと他のブロックまで動く | 自動配置が動かした1件を除いて計算し直され、残りが並び替わっていた。1つ動かした時点で、そのとき自動配置だった分も現在位置で確定するようにした |
| 19 | 同梱サンプルCSVが3列に欠けていた | 配布ファイルそのものを検証していなかった。ファイルを読んで検証する単体テスト(UT-B16〜18)を追加 |
| 20 | ルート表示を消すとGoogleマップのリンクまで消える | リンクをルート概要の中に置いていたため。ルート表示とは独立させ、2件以上あれば常に使えるようにした |
| 21 | マニュアルの図が本文幅まで引き伸ばされて見づらい | パネルの切り出し(幅372px)を840pxまで拡大していた。図ごとに元の大きさで表示し、説明したい操作部分だけを切り出すようにした(総ページ高 19,664px → 15,855px) |
| 22 | Nominatimの規約が求める結果のキャッシュが未実装 | 「同じ問い合わせを繰り返すクライアントはブロックされ得る」と明記されている。`src/geocache.ts` を追加(30日・最大300件) |
| 23 | 公開アプリで使えないOSRMデモサーバーに依存していた | 提供元が「非商用かつ合理的な用途に限る」と定めている。公開ビルドから外し、Googleマップリンクで代替 |

修正内容と設計ドキュメントとの差分は `PROPOSALS.md` を参照。
