1. アプリの開き方

これが一番かんたん dist フォルダの中の PinRoute.html を ダブルクリックしてください。それだけで使えます。

やりがちな失敗 いちばん上にある index.html を直接ダブルクリックしても 動きません。ロゴや入力欄は表示されますが、地図が出ず、検索しても何も起きません。

これは不具合ではなく、ブラウザの安全上の決まりです。パソコンのファイルとして開いたページ (アドレスが file:// で始まるページ)からは、別ファイルのプログラムや装飾を 読み込めないようになっています。PinRoute.html はそれらを1つのファイルにまとめてあるため、そのまま開けます。

dist フォルダが無い場合は、ターミナルで次を実行すると作られます (Node.js が必要です)。 

cd pinroute
npm install
npm run build

そのほかの開き方

方法 手順 向いている場面
1ファイル版 dist/PinRoute.html をダブルクリック 自分のパソコンで使う。人にファイルで渡す
ローカルサーバー npm run preview を実行し、表示された http://localhost:4173 を開く 公開時と同じ状態を確かめたいとき
開発サーバー npm run dev を実行し、表示されたURLを開く ソースを書き換えながら試すとき
Webに公開 dist の中身を GitHub Pages などに置く 誰でも見られるようにするとき

インターネット接続が必要です 地図の画像・地点の検索・ルート計算はインターネット上の無料サービスを使っています。 オフラインでは地図が出ません。

2. 画面の見かた

場所 役割
上部の入力欄 住所や施設名を入力して「検索」を押すと、地図にピンが立ちます
ピン一覧 登録した地点が上から順に並びます。この並び順がそのまま巡回順です
ルート概要 ピンが2件以上になると、総距離と所要時間が表示されます
右の地図 番号付きのピンと、ピンを順に結ぶ経路が表示されます
画面下の注記 地図データの提供元と、データの取り扱いについての説明です

3. 基本の使い方

地点を追加する

  1. 入力欄に住所か施設名を入力します。「東京駅」のような施設名でも、「大阪市北区梅田1丁目」のような住所でも構いません。
  2. 「検索」ボタンを押す(または Enter)と、地点が1つに決まればそのままピンが立ちます。
  3. 同じ手順で2件目、3件目を追加します。ピンは最大20件まで登録できます。

候補が複数出たとき

同じ名前の場所が各地にある場合は、候補が一覧で出ます。名前の下に所在地が出ているので、 目的の場所を選んでください。

ヒント 候補は ↑ ↓ で選んで Enter でも確定できます。 閉じたいときは Esc か右上の × を押してください。

4. ルートを確認する

ピンが2件以上になると、登録した順に結ぶ車のルートが自動で計算され、 地図に線が引かれます。

総距離と所要時間

「Googleマップで開く」を押すと、同じ順番の経路がGoogleマップで開きます。 電車や徒歩での行き方を調べたいときは、こちらを使ってください。

ルートが要らないときは消せる

物件の比較資料として使うときなど、ルート線が邪魔なときは 「車ルートを表示する」のチェックを外してください。 線・総距離・区間の表示がまとめて消え、ピンと情報ブロックだけになります。

外している間はルートの計算そのものを行いません。並び替えても計算は走らないので、 表示を戻したときにあらためて計算します。この設定は次回開いたときも保たれ、共有URLにも含まれます。

区間ごとの距離

地図で場所を確かめる

一覧の番号(オレンジの丸)を押すと、地図がその地点に移動して詳細が表示されます。

5. まとめて入力(物件一覧の貼り付け)

物件名・住所・駅徒歩などの列が並んだ表をそのまま貼り付けて一括で登録できます。 ExcelやスプレッドシートからコピーしたものでもCSVでも構いません。

まず試すなら docs/sample-properties.csv にサンプルを同梱しています(神保町駅から半径500m以内の10件)。 中身をコピーして貼り付ければ、この章の画面がそのまま再現できます。 物件名・賃料・面積は説明用の架空の値で、住所は実在の街区です。

  1. 「まとめて入力」を開き、表を貼り付けます。1行目が見出しなら「1行目は見出し」にチェックを入れたままにしてください。
  2. 「取り込む」を押すと、住所を1件ずつ調べて地図にピンを立てます。進み具合が表示されます。
  3. 住所が見つからなかった行は、理由とともに一覧に残ります。表の住所を直して貼り付け直してください。

住所の書き方 「〒160-0023 東京都新宿区西新宿2-8-1」のように郵便番号が付いていても、 「東京都杉並区高円寺南4-26-8 サンライズマンション101」のように建物名や部屋番号が付いていても取り込めます。 見つからないときは自動的に住所の部分だけで調べ直します。

上限があります ピンは全部で20件までです。表がそれより多い場合、超えた分は取り込まれず、その旨が表示されます。

6. 情報ブロックを地図に載せる

まとめて入力で取り込むと、地図のピンから引き出し線が伸び、 その先のブロックに表の内容が表示されます。競合物件を並べて見せる資料のような使い方ができます。

重ならないように自動で並びます 物件が少なく余裕があるときはピンのすぐ横に、駅の徒歩圏に集まっていて置ききれないときは 地図の左右の端に振り分けて縦に並べます。地図を動かすと並べ直します。 位置を決めたいブロックはドラッグしてください(動かしたものは自動配置の対象から外れます)。

好きな場所に動かす

ブロックの色のついた見出し部分をつかんでドラッグすると、好きな位置に置けます。 引き出し線は自動でついてきます。位置は保存され、地図を動かしても関係が崩れません。

表示する項目と順番を変える

操作 やり方
項目の順番を変える 「情報ブロック」の一覧で ▲ ▼ を押す
項目を出さない その項目のチェックを外す
項目をまとめて切り替える 「すべて表示」「すべて隠す」を押す
ブロックを1つだけ隠す そのブロックの右上の × を押す
ブロックを全部隠す 「地図に情報ブロックを表示する」のチェックを外す
配置を元に戻す 「配置を初期化」を押す(隠したブロックも戻ります)

物件名について 名称の列はブロックの見出しに表示されるため、中の項目としては重ねて表示しません。

色と大きさを変える

「見た目」を開くと、ピン・情報ブロック・引き出し線・ルート線の 色(6色)と大きさ(小・中・大)をまとめて変えられます。

1件だけ目立たせたいときは、ピン一覧の各行にある丸いボタンを押してください。 その地点だけの色と大きさを設定できます。個別に設定した地点は全体の設定より優先されます。 元に戻すときはその場の「全体の設定に戻す」、まとめて戻すときは 「見た目」の中の「個別の設定をすべて解除」を押します。

動かしたブロックは動きません ブロックを1つドラッグすると、そのときの他のブロックの位置もそのまま固定されます。 1つ動かしたせいで別のブロックが勝手に動くことはありません。 自動で並べ直したいときは「配置を初期化」を押してください。

7. 並び替え・名前の変更・削除

順番を変える

ルートは一覧の並び順どおりに計算されます。順番を変えると、 番号もルートも自動で付け直されます。

操作 やり方
1つ上/下へ 行の右にある ▲ ▼ ボタンを押す
好きな位置へ 行の左端の点々をつまんで、移動したい場所へドラッグする

スマートフォンの場合 指でのドラッグには対応していません。▲ ▼ ボタンをお使いください。

名前を変える

一覧の名前をクリックすると、そのまま書き換えられます。Enter を押すか、ほかの場所をクリックすると確定します。Esc で取り消せます。

「A社」「内見1件目」のように自分に分かりやすい名前にしておくと、順番を考えるときに便利です。

削除する

操作 やり方
1件だけ消す その行の右端にある × を押す
すべて消す 「全削除」を押す。確認のメッセージが出るので「OK」を押す

ルート線だけ消したいとき ピンは残したままルートだけ消すなら「車ルートを表示する」のチェックを外してください (4章)。

8. 保存と共有

自動で保存されます

登録したピンはブラウザに自動保存されます。タブを閉じてもパソコンを再起動しても、 次に開いたときに前回の状態が復元されます。保存ボタンはありません。

ほかの人に渡す・別の端末で開く

このURLにはピンの情報がすべて含まれています。メールやチャットで送れば、 相手が開いたときに同じピンとルートがそのまま再現されます。 どこかのサーバーに保存されるわけではありません。

URLが長いとき ピンが多かったり名前が長かったりすると、URLが長くなり 「一部の環境で開けない場合があります」と表示されることがあります。 その場合はピンを減らすか、名前を短くしてください。

9. スマートフォンで使う

画面が狭いときは、上に地図・下に操作パネルの縦並びに切り替わります。機能はパソコンと同じです。

10. キーボード操作

キー 動作
Enter 入力欄で検索を実行。候補を選んでいるときはその候補を確定
↑ ↓ 候補を上下に選ぶ
Esc 候補を閉じる。名前の編集中なら変更を取り消す
Tab ボタンや入力欄を順に移動する

11. 困ったときは

症状 原因と対処
画面は出るが、地図が表示されず検索しても何も起きない index.html を直接開いています。dist/PinRoute.html を開いてください(1章)
「見つかりませんでした」と出る 表記を変えてお試しください。施設名なら正式名称、住所なら「都道府県から」入れると見つかりやすくなります
「検索サーバーに接続できません」と出る インターネットに接続されているか確認してください。しばらく待って再度お試しください
「ルートを計算できませんでした」と出る ルート計算は無料の公開サーバーを使っており、混雑時に応答しないことがあります。 ピンはそのまま残るので、しばらくしてから順番を変えるなどすると再計算されます。 離島など道路がつながっていない地点同士でも計算できません
「ピンは最大20件までです」と出る 不要なピンを削除してから追加してください
思った場所と違うところにピンが立つ そのピンを削除し、より詳しい言葉で検索し直してください。 候補が複数出た場合は、所在地を見て選び直せます
まとめて入力で「住所が見つかりませんでした」と出る 住所の列の指定が違っていないか確認してください。ビル名だけ・地名だけの行は見つかりません。 都道府県から書いた住所にすると確実です
情報ブロックが重なって読めない ブロックの見出しをドラッグして離してください。「配置を初期化」で既定の位置に戻せます
前回のピンが消えている ブラウザの閲覧履歴・サイトデータを消すと、保存内容も消えます。 大事な組み合わせは共有URLを控えておくと安全です

12. データの扱い

  • ピンの情報はお使いのブラウザの中と、発行した共有URLの中にだけ保存されます
  • ログインやアカウント登録は不要です。運営者がピンの内容を見ることはできません
  • 入力した住所やピンの座標は、地点の検索とルート計算のために 国土地理院・Nominatim・OSRM に送信されます
  • 地図の画像は OpenStreetMap から取得しています

この機能はありません

  • 訪問順を自動で最短に並べ替える機能(順番はご自身で調整してください)
  • 徒歩・自転車・電車でのルート計算(「Googleマップで開く」をご利用ください)
  • 地図をクリックしてピンを追加する操作(検索から追加してください)

仕組みを知りたい方へ フォルダの構成、ビルドとは何か、なぜGitHubで公開できるのかを図で説明した how-it-works.html を同じ docs フォルダに置いています(ダブルクリックで開けます)。
